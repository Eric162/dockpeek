# Project instructions

Run `make bootstrap` once. After editing code, run `make format` and `make check`
before reporting completion. Run `make sanitize` for concurrency or memory changes
and `make app` for packaging or executable changes. Report failures plainly.

Use Conventional Commits for commits and PR titles. Keep responses brief.

For Swift changes and quality-tool maintenance, read
[the DockPeek Swift skill](.agents/skills/dockpeek-swift/SKILL.md).
